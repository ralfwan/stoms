# InAs test data

Zincblende InAs from the almaBTE database (J. Carrete, Phys. Rev. B 91,
085202 (2015); VASP PAW LDA): primitive `POSCAR`, `BORN` (Born charges and
dielectric tensor) and the force constants of its 5×5×5 supercell.

`FORCE_CONSTANTS` is the original full (250×250) file rewritten in phonopy's
compact form (2×250), which holds the same numbers in 1/125 of the space.
